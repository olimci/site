Tohru

Dotfiles manager

Tohru is my dotfiles manager. It is a small Go CLI for managing personal machine configuration. The source is on GitHub, and you can see my dotfiles using Tohru here.

The main goal is to be reversible. The application keeps track of what files it manages, so when you unload a profile, it can restore any files back to their original state.
